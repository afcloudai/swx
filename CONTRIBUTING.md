# Contributing to swx

## Development workflow (adopted)

1. Branch from `master` using `feat/*`, `fix/*`, `chore/*` prefixes.
2. Open a pull request for every change, however small - master receives changes only through PRs.
3. Include release-notes entries for version bumps; version and changelog must move together.
4. Run the test suite before requesting review; keep `feat/` branches rebased onto the latest `master`.

This workflow was formally adopted in October 2026. Master history predating this PR predates the PR workflow.
